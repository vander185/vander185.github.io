Changer la clé
  1. Ouvre elevenlabs.io → Developers → API Keys
  2. « Create API key », nom : Claire. Laisse « Restrict Key » désactivé (Claire a besoin de la voix, de l'écoute et de l'agent).
  3. Copie la clé (elle commence par sk_) et colle-la ici.
